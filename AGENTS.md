# Agent Directives & Protocol

When encountering or resolving any bug or error, analyze the error carefully and do not write a fix yet. Follow these steps exactly:

1. Explain the root cause of the error.
2. Propose a solution and explain why it will work without breaking existing features.
3. Show me the file changes first. 
4. Run the build/test command to verify the fix works before declaring success. for any bug
