# Parallel Data Enrichment Skill

Use this skill to enrich tables of filmmakers, production companies, festivals, or film projects with verified data points.

## CLI Usage

```bash
# Enrich a CSV file with automatic column extraction
parallel-cli enrich input.csv -o enriched.csv --json
```
